# 注册模块测试用例
| 用例ID | 模块 | 标题 | 前置条件 | 操作步骤 | 预期结果 | 优先级 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| REG001 | 注册 | 正常注册，填写全部合法信息 | 进入注册页面 | 1.输入未注册手机号<br>2.输入合法密码<br>3.输入确认密码<br>4.获取并填写正确验证码<br>5.勾选用户协议<br>6.点击注册 | 注册成功，自动跳转登录页 | P0 |
| REG002 | 注册 | 手机号为空提交 | 进入注册页面 | 1.手机号留空<br>2.其余信息正常填写<br>3.点击注册 | 提示：手机号不能为空 | P1 |
| REG003 | 注册 | 手机号格式错误 | 进入注册页面 | 1.输入10位手机号<br>2.其余信息正常填写<br>3.点击注册 | 提示：手机号格式不正确 | P1 |
| REG004 | 注册 | 两次密码输入不一致 | 进入注册页面 | 1.输入未注册手机号<br>2.密码123456，确认密码1234567<br>3.填写验证码，勾选协议<br>4.点击注册 | 提示：两次输入密码不一致 | P1 |
| REG005 | 注册 | 已注册手机号再次注册 | 进入注册页面 | 1.输入已存在账号手机号<br>2.其他信息正常填写<br>3.点击注册 | 提示：该手机号已注册 | P1 |
