# 登录模块测试用例
| 用例ID | 模块 | 标题 | 前置条件 | 操作步骤 | 预期结果 | 优先级 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| TC001 | 登录 | 账号密码正确登录 | 进入登录页面 | 1.输入正确用户名<br>2.输入正确密码<br>3.点击登录 | 登录成功，跳转首页 | 高 |
| TC002 | 登录 | 密码错误 | 进入登录页面 | 1.输入正确用户名<br>2.输入错误密码<br>3.点击登录 | 提示密码错误，不跳转 | 高 |
| TC003 | 登录 | 用户名为空 | 进入登录页面 | 1.用户名留空<br>2.输入密码<br>3.点击登录 | 提示请输入用户名 | 高 |
